# Data

This folder is reserved for the dataset used in this project.

The raw dataset is not uploaded to this repository to avoid sharing large or private files.

To run the notebook locally, place the dataset here and update the file path inside the notebook.

Suggested dataset:
- Online Retail / Online Sales transaction dataset

Expected fields:
- Invoice
- StockCode
- Description
- Quantity
- InvoiceDate
- Price
- Customer ID
- Country
